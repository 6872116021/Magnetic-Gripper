# Pneumatic-Actuated Magnetic Gripper

This project features a custom-engineered **Magnetic Gripper** designed for automation and robotic applications. The core of the mechanism is powered by a high-quality pneumatic actuator, providing reliable and fast gripping cycles.

## 🛠 Actuator Specifications
The housing is specifically designed to accommodate the:
* **Brand:** SMC
* **Model:** [CQSB12-5D](https://www.smcworld.com) (Compact Cylinder: Double Acting, Single Rod)


## ✨ Key Features
* **Precision Housing:** Custom-designed frame that perfectly fits the SMC CQSB12-5D cylinder.
* **Pneumatic Control:** Uses a double-acting system for positive engagement and disengagement of the magnetic force.
* **Compact Design:** Ideal for small-scale robotic arms or end-of-arm tooling (EOAT).
* **Versatile Mounting:** Includes mounting holes for easy integration into various mechanical systems.

## 📦 Hardware Requirements
1.  **SMC CQSB12-5D** Pneumatic Cylinder.
2.  **Magnetic Assembly:** Internal permanent magnets moved by the cylinder.
3.  **Pneumatic Fittings:** M5 threaded push-to-connect fittings.
4.  **Control Valve:** 5/2 way Hand Lever Valve (e.g., 4H210-08) or Solenoid Valve.
5.  **Custom Housing:** CAD files provided in this repository (Base & Box projects).

## ⚙️ How it Works
The gripper operates by using the pneumatic cylinder to shift the position of internal permanent magnets:
* **Extend (ON):** The cylinder pushes the magnet close to the contact surface, engaging the magnetic field to pick up ferrous parts.
* **Retract (OFF):** The cylinder pulls the magnet away (or into a shielded position), neutralizing the external magnetic pull to release the part.
